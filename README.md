# Countdown Timer

A simple countdown timer built using HTML, CSS, and JavaScript.

The timer calculates the remaining time until a specified future date and displays the remaining days, hours, minutes, and seconds.

## Features

- Displays remaining days
- Displays remaining hours
- Displays remaining minutes
- Displays remaining seconds
- Updates automatically every second
- Zero-padding for single-digit values
- Simple and responsive interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

The project uses JavaScript's `Date` object to calculate the difference between the current date and the target date.

`setInterval()` updates the countdown every second and dynamically updates the values displayed on the page.
